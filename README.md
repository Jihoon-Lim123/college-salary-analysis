Jupyter notebook that analyzes U.S. college salary outcomes using the common starting- and mid-career pay dataset. The notebook cleans and validates the data (types, missing values, outliers), explores distributions by region and school type, and engineers a mid-career salary “uplift” metric that compares each school to its region’s baseline so cross-region comparisons are fair. It then fits simple linear models—first a baseline using starting salary, then models with Region × School-Type interaction terms—to check how much those factors add to explanatory power and how results should be interpreted. Key figures summarizing trends and variability are generated directly from the code, and assumptions/limitations are documented inline for transparency. The project is lightweight and reproducible (minimal dependencies listed in requirements.txt); open college_salary_final_project.ipynb to view or run the full analysis.
